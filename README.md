# גיאואינט (GEOINT)

כלי ווב למיצוי מיקום מתמונה. מעלים תמונה, והמערכת:

1. **מחלצת מטא-דאטה (EXIF)** בדפדפן (exifr) — GPS, מצלמה, חותמת זמן, תוכנה. לא נשלח לשרת.
2. **מנתחת רמזים חזותיים** בשרת עם מודל הראייה `@cf/moondream/moondream3.1-9B-A2B` (Cloudflare Workers AI) — 6 שאילתות מומחה: תיאור כללי, שילוט וטקסט, כביש ורכב, סביבה ואדריכלות, אור וצללים, הערכת אזור זהירה (JSON בלבד).
3. **חישוב אסטרונומי** — מיקום שמש (אזימוט/גובה) מתוך חותמת זמן + מיקום, להצלבה מול צללים.
4. **כלל ברזל:** אם אין ראיות — לא מסמנים מיקום. מוצגים רק הרמזים שזוהו. סיכה אדומה על המפה = GPS מ-EXIF בלבד; סיכה צהובה = אינדיקציה חזותית (לא ודאית) שעברה גיאוקודינג.

## סטק

- Cloudflare Worker + Workers AI (vision) + Static Assets. כולו על ה-Free tier (~10,000 neurons ליום ≈ עשרות ניתוחים).
- דף יחיד, עברית RTL, בלי בנייה — `public/index.html` + ספריות vendored ב-`public/vendor/` (exifr, Leaflet).
- מפה: OpenStreetMap tiles · גיאוקודינג: Nominatim (דרך ה-worker, עם User-Agent מסודר).
